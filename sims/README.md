# Sims

One folder per simulation, named after what it shows (`projectile`, `rocket-equation`, ...).

Each folder should have:

- the source (for Manim: the `.py` scene file)
- a short `README.md`: which week and lesson it comes from, what physics it shows, how to run it
- a `preview.png` or `.gif` for the card on the tracker page

Then add it to `../projects.js`.
